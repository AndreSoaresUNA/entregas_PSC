# Entregas PSC
Programação de Soluções Computacionais — Java — professor André Soares.

## Aula 2
Leia [os desafios](DESAFIOS.md) e [o guia de entrega](GUIA_ENTREGA.md).
Faça a missão 1 e pelo menos uma missão de sua escolha. Use dados fictícios.

**Entrega:** fork deste repositório → sua pasta → commit e push no fork → pull request para este repositório.
Não é necessário convite de colaborador. Push direto neste repositório não está liberado para a turma.

Estrutura:
```text
entregas/aula2/SEU_USUARIO/
    README.md
    Desafio01.java
    Desafio02.java (ou outra missão)
```
No README use o modelo em [MODELO_README.md](MODELO_README.md). Não altere pastas de colegas. Envie fontes; não envie .class ou dados pessoais.
O PR aberto registra a entrega; correções por novos commits na mesma branch.
Prazo e turma serão informados pelo professor em sala.
